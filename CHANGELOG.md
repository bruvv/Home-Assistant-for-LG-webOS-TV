# Changelog

## [Unreleased]

### Added
- Glasshouse custom catalog (`repo.json`) for app discovery and update checks.
- Automatic catalog refresh using the published IPK's SHA-256 and size.
- Catalog generation tests and Glasshouse setup instructions.

## [1.1.0] - 2026-11-08

First published v1 release.

### Added
- Fullscreen Home Assistant launcher for LG webOS TVs with a saved server URL.
- Direct Home Assistant navigation and authentication without an iframe.
- Optional Home Assistant-side scrolling helper for LG webOS, including Magic Remote wheel handling and fallback Up/Down buttons.
- English launcher interface and setup instructions.
- Python standard-library IPK builder.
- GitHub Actions package builds and automatic versioned releases with downloadable IPK and scrolling helper.
- Package archive checks covering metadata and bundled app files.
